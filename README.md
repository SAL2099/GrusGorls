## KindFindMobile:
### Running the app

1. Go to the project folder:
   cd KindFindMobile

2. In terminal (one time): 
   npm i -g expo

3. Install dependencies (one time): 
   npm install 

4. Start Expo:
   npx expo start 

5. Run on a device:
   Scan the QR code with Expo Go (Android)
   Scan with the Camera app (iOS)

   Or press:
   w for web preview
