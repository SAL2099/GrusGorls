## KindFindMobile:
### Running the app

1. Go to the project folder:
   cd KindFindMobile

2. In terminal (one time): 
   npm i -g expo

3. Install dependencies (one time): 
   npm install 

4. Start Expo:
   npx expo start (normal wifi)
   npx expo start --tunnel (edumroam)


5. Run on a device:
   Download the Expo Go app:
      Scan the QR code with Expo Go (Android)
      Scan with the Camera app (iOS)
      (Make sure you are on the same network and do not have a vpn on as it can block it from loading)
